# Lagerkollen

Mobilanpassad lager- och orderchecklista för saknade artiklar.

## Funktioner
- Flera ordrar och orderhistorik
- Massinmatning av artikelnummer
- Status: Saknas / Hittad / Ej hittad
- Sparade lagerplatser per artikel
- Sökning, filtrering och sortering
- Lokal lagring och JSON-backup
- PWA-stöd för hemskärmen och grundläggande offline-läge

Data lagras lokalt i webbläsaren och ligger inte i GitHub-repot.
